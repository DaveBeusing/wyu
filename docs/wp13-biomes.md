# WP13 · Biomes from ground to orbit

Far Horizon uses the visual recipe `wyu.reference-biomes.v1`. The seed rotates and tilts a band axis in canonical planet space. Terrain relief is represented in the same coordinates as the mesh. The table blends meadow, steppe and highland using quantized smooth weights that sum to 255. Tie order is meadow, steppe, highland. Basalt and ochre share the palette, with a red-channel tint for ochre. The recipe and its shared 1,024-entry lookup table are derived at runtime. WP12 Ember Caves uses its geology palette.

The near upload callback and the orbital patch builder call the same color evaluator. Camera and local render origin are outside its inputs. Each evaluation allocates zero managed bytes after initialization. The existing vertex buffers, upload path, draw topology and orbit landing marker carry the colors.

## Windows checks

The gameplay regression compares seeds 42 and 20261111 at 486 canonical control points per seed, including 92 points shared by cube charts. It checks exact normalized weights, three dominant zones, blended samples, distinct seeds and reversed parallel replay.

Run `pwsh -File eng/Measure-BiomeRendering.ps1` after the verified consumer build. It uses seed 42 for paired NVIDIA walking and flight replays, warms up each mode, and writes raw logs and CSVs. The replays record host submission through observed Present, CPU staging, globe build and renderer handoff. The measurement build disables the Debug Layer in both modes to keep the long replay below its diagnostic message cap. Normal graphics smoke tests use Debug Layer and DRED. The client disables Quick JIT for loops so that the first terrain pack and globe build compile their loop methods once instead of recompiling them inside the loop.

The renderer compiles and evaluates the fixed color callback when opening a reference planet and reuses it after a handoff. The globe allocates its final buffer sizes up front, reuses colors for canonical patch-edge samples, and stops height iteration when the result reaches a fixed point. The near and far renderers use one Groundwork D3D12 device in sequence. Each handoff settles the prior renderer and releases its swap chain before the next owner binds the window. After the first far frame, the flight stages its return terrain within the streaming budget. The CPU build runs privately against the held return view and the preflight terrain revision. At the handoff, the near renderer binds that view, submits the neutral mask and publishes the prepared terrain through the normal native and Core gates. Aborting cancels and joins the private build before host teardown.

The benchmark logs QPC intervals, thread CPU cycles, process-wide Gen 0 collection counts and managed allocation bytes around synchronous near packing and globe building. Cycles track work on the measured thread and can vary with core frequency. Collection counts show overlap with GC and do not measure pause time. The allocation totals include returned buffers, so they are conservative bounds for the managed temporary memory of each build. For GPU measurements without a tracing session, sample the Windows GPU Engine running-time counters for the replay process and intersect their intervals with the QPC phase windows. These counters give sampled engine busy time. Short boundary intervals and per-frame GPU percentiles require a finer trace.
