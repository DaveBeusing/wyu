# Worlds Yet Unseen (WYU)

Worlds Yet Unseen is a first-person planetary survival and exploration game. It uses the separate Groundwork engine repository.

The game is planned around procedurally generated, spherical and destructible voxel worlds, seamless surface-to-orbit travel, and modular construction. Its initial implementation is single-player on Windows.

Engine code belongs in Groundwork; gameplay rules and content belong in WYU.
